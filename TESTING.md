# Minecraft 1.20.1 Servux paste testing

## Recorded results

| Check | Result |
| --- | --- |
| Client startup | The Litematica backport loaded in Minecraft Java Edition 1.20.1 with Fabric and MaLiLib 0.16.0. |
| Server startup and handshake | The Fabric 1.20.1 server started, registered the `servux:litematics` channel, and returned its metadata. |
| Client-to-server protocol test | Placement NBT generated by the client was sent to the server in a protocol test. A 1 × 1 × 1 stone schematic pasted successfully, and `execute if block` confirmed the block. |
| Multiplayer paste | The project author tested a 252-block schematic on a Fabric 1.20.1 server. The server log recorded direct pasting with no `/fill` commands. |

The multiplayer result was reported in [Litematica PR #423](https://github.com/sakura-ryoko/litematica/pull/423) and the [Servux v0.1.2-pos release](https://github.com/Inkpaper-mz/servux-1.20.1/releases/tag/v0.1.2-pos).
